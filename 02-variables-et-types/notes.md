# Variables et types

Une variable stocke une valeur en mémoire sous un nom. Python détermine son type automatiquement (entier, flottant, chaîne, booléen) selon la valeur assignée.

## Exemple

```python
age = 25            # int
taille = 1.75        # float
prenom = "Gius"       # str
est_actif = True      # bool

print(prenom, "a", age, "ans")
```
