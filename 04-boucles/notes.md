# Boucles

![Illustration : flèches de répétition](https://cdn.jsdelivr.net/gh/twitter/twemoji@14.0.2/assets/72x72/1f501.png)

Les boucles `for` et `while` permettent de répéter des instructions. `for` parcourt une séquence, `while` s'exécute tant qu'une condition est vraie.

## Exemple

```python
for i in range(5):
    print("Itération", i)

compteur = 0
while compteur < 3:
    print("Compteur :", compteur)
    compteur += 1
```
