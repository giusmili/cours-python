# Boucles

Les boucles `for` et `while` permettent de répéter des instructions. `for` parcourt une séquence, `while` s'exécute tant qu'une condition est vraie.

## Exemple

```python
for i in range(5):
    print("Itération", i)

compteur = 0
while compteur < 3:
    print("Compteur :", compteur)
    compteur += 1
```
