# 05 — Benchmark des plateformes interactives

Nom de la famille : **plateformes d'apprentissage interactif et de pratique**.

Sous-catégories : challenge-based learning, game-based learning, labs/cyber ranges, project-based learning.

Le but n'est pas de copier leurs énoncés ou leur design, mais d'étudier les mécaniques qui donnent envie de continuer.

## Priorité francophone
### France-IOI — https://www.france-ioi.org/
Progression, éditeur intégré, validation automatique, suivi enseignant, gros volume d'exercices.

### CodinGame — https://www.codingame.com/start/fr/
Benchmark majeur pour nos missions généralistes : scénarios visuels, puzzles courts, feedback immédiat, nombreux langages dont Python et JavaScript. À regarder : Onboarding, The Descent, Temperatures, Mars Lander.

### Root Me — https://www.root-me.org/
Benchmark futur SISR/cyber : challenges, environnements, difficulté et sensation de terrain.

### MDN Learn — https://developer.mozilla.org/fr/docs/Learn_web_development
Bon compromis manuel/pratique avec tests de compétences, défis et Playground.

### Grid Garden — https://cssgridgarden.com/
Très bon exemple de puzzle spatial pour CSS Grid.

## Programmation générale
### Exercism — https://exercism.org/
Tracks Python/JavaScript, exercices conceptuels, analyse automatique, mentorat et déblocage. Son “Hello World” sert surtout à apprendre le workflow : excellent modèle de Mission zéro.

### Codewars — https://www.codewars.com/
Kata, difficultés graduées, tests automatiques, plusieurs bonnes solutions. Très bon pour les défis de maîtrise.

### CheckiO — https://checkio.org/
Python/TypeScript, îles, missions, progression, usage classe. Très proche de “vraie programmation + monde de jeu”.

### CodeCombat — https://codecombat.com/
Aventure narrative avec vrai code Python/JavaScript. À observer : onboarding, objectifs visibles, gratification.

## Web / Front-end
### CSSBattle — https://cssbattle.dev/
Reproduire une cible en HTML/CSS. Excellent feedback visuel. Ne pas faire du code-golf l'objectif pédagogique principal.

### Flexbox Froggy — https://flexboxfroggy.com/
24 niveaux pour apprendre Flexbox par manipulation spatiale.

### Grid Garden — https://cssgridgarden.com/
Équivalent réussi pour CSS Grid.

### Frontend Mentor — https://www.frontendmentor.io/challenges
Briefs/designs à reconstruire, du débutant à l'avancé. Très bon modèle pour nos missions de maîtrise.

### CodePen Challenges — https://codepen.io/challenges
Prompts ouverts, starter, partage et créativité.

### Scrimba
- https://v1.scrimba.com/learn/htmlandcss
- https://scrimba.com/learn/learnjavascript
Contenu éditable, micro-défis, projets.

### freeCodeCamp — https://www.freecodecamp.org/learn/
Project-based learning systématique : pages, formulaires, jeux et mini-apps.

### roadmap.sh Frontend Projects — https://roadmap.sh/frontend/projects
Réservoir de briefs classés par niveau.

## Cyber / SISR
### TryHackMe — https://tryhackme.com/
Rooms, walkthrough/challenge, tâches successives, validation, lab navigateur, progression sauvegardée.

### OverTheWire Bandit — https://overthewire.org/wargames/bandit/
Excellent modèle minimaliste : chaque niveau donne juste ce qu'il faut pour atteindre le suivant. SSH, Unix, permissions, réseau, Git...

### picoCTF — https://www.picoctf.org/
À suivre pour CTF, scénarios et cyber éducative.

## Algorithmique
### LeetCode — https://leetcode.com/
Excellent pour la pratique algorithmique ; mauvais modèle pour introduire une variable à un débutant absolu.

## Sandboxes
### CodePen — https://codepen.io/
Laboratoire HTML/CSS/JS : preview instantanée, fork, starter, partage.

### MDN Playground
Éditeur/preview simple, sans chercher à devenir un IDE complet.

## Règle de réutilisation
1. **Observer** : mécanique, UX, rythme, feedback, structure pédagogique.
2. **Lier** : renvoyer vers une ressource utile.
3. **Copier/adapter** : uniquement avec licence explicitement compatible ou autorisation.

Sans licence claire : ne pas copier l'énoncé, les assets, le design ou le code ; créer une mission originale inspirée du mécanisme général.
