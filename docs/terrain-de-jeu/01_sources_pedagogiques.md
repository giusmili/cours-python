# 01 — Sources pédagogiques

Ces ressources servent à étudier la progression, les explications, la granularité des exercices et les choix pédagogiques. Consulter ou lier une ressource n'autorise pas automatiquement sa republication.

## Vincent Le Goff — Apprenez à programmer en Python, 5e éd. (2026)
**Référence Python principale.** Mise à jour pour Python 3.14+.

Progression utile : premières instructions, variables/types, conditions, boucles, fonctions/modularité, exceptions, chaînes, listes, dictionnaires, fichiers, POO, bibliothèque standard.

À regarder en priorité : avant-propos, chapitres débutants, TP (casino, pendu, jeu de cartes), réseau/système, tests et debug.

Lien : https://www.editions-eyrolles.com/livre/apprenez-a-programmer-en-python-5e

Licence : livre commercial. Analyse/référence oui ; reproduction non.

## University of Helsinki — Python Programming MOOC
- https://programming-26.mooc.fi/
- https://github.com/rage/programming-26

## FUN MOOC — Apprendre à coder avec Python
https://www.fun-mooc.fr/fr/cours/apprendre-a-coder-avec-python/

Référence francophone : débutant total, capsules courtes, exercices, quiz, validation automatique, projet et escape game pédagogique.

## MDN — Learn Web Development
