# Fonctions

![Illustration : engrenage](https://cdn.jsdelivr.net/gh/twitter/twemoji@14.0.2/assets/72x72/2699.png)

Une fonction regroupe du code réutilisable sous un nom, avec des paramètres en entrée et une valeur de retour optionnelle (`return`).

## Exemple

```python
def saluer(nom):
    return f"Bonjour, {nom} !"

message = saluer("Gius")
print(message)
```
