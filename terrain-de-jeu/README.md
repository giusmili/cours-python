# Terrain de jeu

Application interactive du projet.

Branche de référence : `kevin/missions`.

Le code applicatif sera initialisé ici sur une branche `dev/<sujet>`, puis intégré dans `kevin/missions` après tests.

Voir `../docs/terrain-de-jeu/README.md` pour le cadrage.

Roadmap UX éditeur : coloration syntaxique par langage + numéros de ligne, avec CodeMirror 6 comme piste privilégiée (`../docs/terrain-de-jeu/03_roadmap_prototype.md`).

`master` n'est pas une cible de ce chantier.
