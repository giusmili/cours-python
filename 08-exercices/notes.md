Cette section rassemble des exercices pratiques combinant les notions précédentes (variables, conditions, boucles, fonctions) pour consolider les acquis.

## Exemple

```python
def est_pair(nombre):
    return nombre % 2 == 0

for n in range(10):
    if est_pair(n):
        print(n, "est pair")
```
